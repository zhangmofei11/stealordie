HEIST WALKTHROUGH

Complete guide to planning and executing the perfect heist

📋 PRE-HEIST PLANNING

1. Scout the Location

Study guard patrol routes and shift change timings.

  • • Note camera positions and blind spots
  • • Identify guard patrol patterns
  • • Find optimal entry and exit points

2. Assign Roles

Distribute team roles based on abilities and item loadouts.

  • • Distracter: Draw guard attention
  • • Thief: Execute the steal
  • • Getaway: Prepare escape route

🏦 LEVEL-BY-LEVEL GUIDE

Level 1: The Jewelry Store

Tutorial level. Learn basic mechanics.

Strategy: Wait for guard to check display case, grab item, exit through back door.

Level 2: The Bank Vault

First real challenge with multiple guards.

Strategy: Use vent system. Distract guards with noise. Vault code changes daily - watch for admin announcements.

Level 3: Museum Heist

Laser grids and cameras. Requires precise timing.

Strategy: Disable cameras first. Time movements between laser sweeps. Partner required for pressure plates.

Level 4: Casino Night

High security, multiple objectives, time pressure.

Strategy: Infiltrate as VIP guest. Access restricted areas with disguise. Collect all 3 items before alarm triggers.

🏃 ESCAPE ROUTES

Primary Exit

Main route marked on minimap. Usually heavily guarded after alarm.

Vent System

Secret passages connecting key areas. Guard detection reduced.

Rooftop Access

Emergency escape via skylights. Requires climbing items.
